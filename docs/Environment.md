# Переменные окружения

| Переменная           | Обязательна | Описание                                                                                                                                                  |
| -------------------- | :---------: | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `DATABASE_URL`       |     да      | Строка подключения PostgreSQL. Для serverless — пул.                                                                                                      |
| `NEXTAUTH_SECRET`    |     да      | Секрет подписи JWT. `openssl rand -base64 32`.                                                                                                            |
| `NEXTAUTH_URL`       |  да (прод)  | Публичный URL приложения.                                                                                                                                 |
| `LOG_LEVEL`          |     нет     | `debug`\|`info`\|`warn`\|`error` (по умолчанию info в проде).                                                                                             |
| `TELEGRAM_BOT_TOKEN` |     нет     | Токен бота от @BotFather — включает Telegram-канал уведомлений о новых заявках. Без него канал молча не отправляет (лог предупреждения один раз).         |
| `TELEGRAM_CHAT_ID`   |     нет     | Chat id, куда слать уведомления (см. `https://api.telegram.org/bot<token>/getUpdates` после первого сообщения боту). Нужен вместе с `TELEGRAM_BOT_TOKEN`. |

Пример — в `.env.example`. Файл `.env` не коммитится.
