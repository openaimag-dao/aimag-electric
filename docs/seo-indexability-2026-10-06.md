Добавлена повторяемая проверка приоритетных посадочных страниц, категорий и семи статей о закупке:

Первый полный прогон: 14 из 14 страниц прошли все проверки, код выхода 0.

```sh
python3 scripts/check-seo.py
```

Скрипт выполняет только GET-запросы. Проверяет код ответа, неожиданные перенаправления, canonical, noindex, robots.txt и присутствие URL в sitemap. Код выхода 1 означает найденную проблему или недоступность проверки. Это ручная проверка, расписание не настроено.

Доступность для поискового робота не подтверждает фактическую индексацию. Для следующего этапа нужны данные Google Search Console: статус индексирования посадочных страниц, показы, клики, запросы и средняя позиция. До их получения нельзя утверждать рост охвата или органических продаж.
